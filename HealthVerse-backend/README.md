\# HealthVerse AI



HealthVerse AI is an intelligent digital healthcare platform that provides personalized health management, wellness tracking, medicine management, nutrition and fitness recommendations, medical report analysis, and AI-powered health insights.



\## Backend



The backend is built using:



\- Java 21

\- Spring Boot

\- PostgreSQL

\- Spring Security

\- BCrypt

\- JWT

\- Maven



\## Project



HealthVerse AI follows a microservices architecture with services for authentication, user health, medicine, reports, nutrition, fitness, analytics, notifications, and AI integration.
